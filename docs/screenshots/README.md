# Сценарий демонстрации

Кадры следует снимать на симуляторе iPhone после запуска сервера. Переключение ролей выполняется через «Выйти» и повторный вход.

| Время | Действие | Кадр |
| --- | --- | --- |
| 00:00–00:07 | На экране NEK выбрать «Клиент» | Экран входа |
| 00:07–00:23 | Выбрать услугу, специалиста, завтрашний день и подтвердить время | Выбор окна и подтверждение |
| 00:23–00:32 | Открыть «Мои визиты» | Созданная запись |
| 00:32–00:46 | Выйти, войти администратором, открыть нужный день | Визит в календаре |

Из чистой копии с установленными Xcode и Node.js 24 скриншоты и ролик создаёт `bash tests/record-demo.sh`. Скрипт запускает сервер на порту 8080 с временной БД, поэтому перед запуском нужно остановить сервер Compose. Можно передать UUID отдельного симулятора. Тест с помощью XCTest проходит сценарий входа и записи в обеих ролях. Кадры сохраняются здесь, ролик — в `docs/demo.mp4`.
