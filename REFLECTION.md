# Рефлексия

Из исходного проекта перенесены визуальные компоненты и правило занятости. Разработаны компактный SwiftUI-клиент, REST API и локальная модель SQLite. Компоновка позволяет на защите показать один визит с обеих ролей.

На сервере полезнее всего было явно зафиксировать правило пересечения и проверить пару одновременных запросов. Если свободное окно занято между выбором и подтверждением, приложение получает сообщение от сервера и обновляет расписание. Сохранённая запись доступна и клиенту, и администратору после перезапуска сервера.

Пять серверных тестов прошли. Compose-конфигурация прошла проверку синтаксиса. Собран бинарник для iOS Simulator. Проверка контейнера и экранного сценария требует работающих Docker Engine и CoreSimulator.

В учебном объёме реализован один филиал, клиентские записи и чтение календаря администратором. Каталог и учётные записи демонстрационные.
