# Ошибки и исправления

| Наблюдение | Что сделали |
| --- | --- |
| Xcode SDK обрабатывал `@State` как макрос. В ограниченной среде компилятор не мог запустить вложенную песочницу SwiftUI-макроса. | Использовали псевдоним стандартной обёртки `SwiftUI.State`. После исправления сборка прошла. |
| Второй клиент может выбрать окно до того, как первый подтвердит запись. | Проверка пересечения и вставка выполняются в одной транзакции. В тесте один запрос получил 201, второй — 409. |
| В локальной среде не было доступного Docker Engine, а адрес loopback недоступен для открытия порта из процесса проверки. | Проверили синтаксис Compose и выполнили тесты API во входном обработчике с SQLite. |
| CoreSimulator не принимал соединение от среды проверки. | Собрали бинарник с SDK симулятора. Проверка запуска и запись кадров требуют рабочей сессии CoreSimulator. |
